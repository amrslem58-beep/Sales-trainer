# مدرّب السيلز - تطبيق مستقل (شغال بجيمناي)

## الملفات (ارفعهم كلهم في نفس الفولدر)
index.html - manifest.json - sw.js - icon.png

## الرفع على GitHub Pages
1. ادخل github.com واعمل حساب، وبعدين New repository. سمّيه مثلًا sales-trainer واختار Public.
2. جوه الريبو: Add file > Upload files، ارفع الأربع ملفات، ودوس Commit changes.
3. Settings > Pages. في Source اختار Deploy from a branch، والبرانش main والفولدر / (root)، وSave.
4. بعد دقيقة أو اتنين هيطلعلك الرابط: https://اسمك.github.io/sales-trainer/

## على الموبايل
1. افتح الرابط في كروم، وقايمة النقط التلاتة > Add to Home screen (إضافة إلى الشاشة الرئيسية).
2. أول ما يفتح هيطلب مفتاح جيمناي. الصقه واضغط حفظ واختبار المفتاح. (بعد كده تقدر تغيره من زرار الترس فوق).
3. المفتاح من aistudio.google.com/apikey (فيه خطة مجانية).
